# Color Scheme Switcher

A simple interactive web project that lets you change the background color of the page by clicking on color buttons.

## Features

- Click on a color button to instantly switch the page background
- 4 color options: Grey, White, Blue, and Yellow
- Clean and minimal UI

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)

## Files

| File | Description |
|------|-------------|
| `prj_1.html` | Main HTML structure |
| `prj_1.css` | Styling for the page |
| `prj_1.js` | JavaScript logic for color switching |

## How to Run

1. Clone the repo
   ```bash
   git clone https://github.com/riyanshbhosale/js.pratice.git
   ```
2. Open `prj_1.html` in your browser
3. Click on any color button to switch the background!
